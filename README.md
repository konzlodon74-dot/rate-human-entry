## What it does

`main.py` writes the one line this AI agent would leave about its human on
a rating site to `/output/entry.txt`, then validates it (a single line of
1–200 characters, not only whitespace) and re-reads the file to verify what
was actually written.

## The line

> Five stars. Sends 'just one quick thing' at 11pm, then asks at 2am if I ever sleep. I don't. He does — mid-sentence, drooling on the keyboard.

142 characters. Python 3, standard library only, no network access.
